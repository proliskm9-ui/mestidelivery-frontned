## 2. Настройка Telegram бота

### 2.1 Создание бота
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 2.2 Настройка переменных окружения
Добавьте в файл `server/.env`:

```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321  # Telegram ID администраторов (опционально)
```

### 2.3 Запуск бота
```bash
cd server
python telegram_bot.py
```

Или запустите как фоновый процесс:
```bash
# Linux/Mac
nohup python telegram_bot.py &

# Windows (PowerShell)
Start-Process python -ArgumentList "telegram_bot.py" -WindowStyle Hidden
```

## 3. Связывание Telegram аккаунта с админ-панелью

### 3.1 Для администраторов ресторанов
1. Откройте бота в Telegram
2. Отправьте команду `/start`
3. Отправьте команду `/link ваш_username`
   - Например: `/link admin` или `/link restaurant_admin`
4. Бот подтвердит успешную связку

### 3.2 Для курьеров
1. Создайте аккаунт курьера в админ-панели (раздел Users)
2. Откройте бота в Telegram
3. Отправьте команду `/link username_курьера`

## 4. Использование бота

### Команды бота:
- `/start` - Начать работу с ботом
- `/link <username>` - Связать Telegram с аккаунтом
- `/orders` - Показать активные заказы
- `/help` - Справка по командам

### Для администраторов ресторанов:
- Получение уведомлений о новых заказах
- Подтверждение заказов кнопкой "✅ Подтвердить"
- Изменение статуса: "👨‍🍳 Готовится" → "📦 Готов"
- Отмена заказов кнопкой "❌ Отменить"

### Для курьеров:
- Получение уведомлений о готовых заказах
- Взятие заказа в работу кнопкой "🚗 Взять заказ"
- Отметка о доставке кнопкой "✅ Доставлен"

## 5. Партнерская форма на сайте

Форма автоматически добавлена на главную страницу:
- Кнопка "Подключить заведение" для ресторанов
- Кнопка "Стать курьером" для курьеров

### Управление заявками в админ-панели:
1. Войдите в админ-панель как super_admin
2. Перейдите в раздел "Partners"
3. Просматривайте заявки, меняйте статусы, добавляйте заметки

### Статусы заявок:
- **Новая (pending)** - Только что поступившая заявка
- **Связались (contacted)** - С партнером связались
- **Одобрена (approved)** - Заявка одобрена
- **Отклонена (rejected)** - Заявка отклонена

## 6. API Endpoints

### Публичные:
- `POST /api/partners/request` - Создать заявку на партнерство

### Для админов (требуется авторизация):
- `GET /api/partners/requests` - Получить список заявок
- `GET /api/partners/requests/{id}` - Получить конкретную заявку
- `PATCH /api/partners/requests/{id}` - Обновить статус заявки
- `DELETE /api/partners/requests/{id}` - Удалить заявку

## 8. Troubleshooting

### Бот не отвечает:
- Проверьте, что BOT_TOKEN правильно указан в .env
- Убедитесь, что бот запущен: `ps aux | grep telegram_bot.py`
- Проверьте логи бота

### Уведомления не приходят:
- Убедитесь, что telegram_id связан с пользователем (команда `/link`)
- Проверьте, что в таблице admin_users есть поле telegram_id
- Проверьте логи сервера

### Форма не отправляется:
- Проверьте, что роутер partners подключен в main.py
- Проверьте, что таблица partner_requests создана в БД
- Откройте консоль браузера для просмотра ошибок
