## 1. Саммари

Отдельные экраны сделаны вкусно: тёмная палитра, один акцент, фото еды, glass-навбар. Премиальность ломают не отдельные страницы, а **отсутствие системы между ними** и **несколько «сайтовых» признаков на уровне платформы**:

- **79 разных hex-цветов и 119 rgba.** Бренд-зелёный захардкожен 282 раза, а `var(--primary)` используется 53 раза. `--primary`, `--card-bg`, `--text-muted`, `--primary-glow` переопределяются в 5 CSS-файлах страниц, **каждый раз с другими значениями**.
- **6 шрифтовых семейств** (Montserrat, Inter, Outfit, Plus Jakarta Sans, Rubik, Segoe UI), **50 разных font-size**, 17 значений letter-spacing. Google Fonts подключаются через `@import` в 10 разных CSS-файлах. Грузинский (KA) не покрыт ни одним из этих шрифтов.
- **88 уникальных box-shadow, 14 радиусов блюра, 28 значений border-radius, 40 уровней z-index** (вплоть до `2147483647`).
- **Motion:** 98× `transition: all`, 289 длительностей ≥350 мс, 39 бесконечных анимаций (15 из них в хедере), 1 правило `prefers-reduced-motion`, 0 exit-анимаций, 0 жестов у шторок.
- **Mobile-native:** зум запрещён (`user-scalable=no`), 83 `:hover` без гейта, 33× `100vh`, нет `overscroll-behavior`, нет истории навигации (Android «назад» закрывает приложение), в `manifest.json` иконка `vite.svg`.
- **Утечка CSS админки и партнёрки в клиент.** Проверено на проде: клиенту прилетают Tailwind preflight, `body { user-select: none }` из партнёрки (нельзя скопировать адрес или номер заказа) и `body { font-weight: 500 }` из админки.

## 2. Предлагаемая дизайн-система (токены)

Все значения взяты из того, что уже чаще всего используется в коде. Цель — зафиксировать фактический стиль, а не придумать новый.

### 2.1 Цвет — роли, а не hex

```css
/* src/styles/tokens.css */
:root {
  /* Canvas & surfaces — лестница светлоты вместо теней (на тёмном тени почти не видны) */
  --color-bg:            #151514;  /* уже --bg; сейчас также #0A0A0A, #0C0C0C, #111, #000 */
  --color-surface-1:     #1C1C1B;  /* карточки. Заменяет #191917, #1A1A1A, #1C1C1E, #181818, #161616 */
  --color-surface-2:     #242423;  /* поднятые: шторки, инпуты. Заменяет #222, #2A2A2A, #2C2C2E, #1F1F1E */
  --color-surface-3:     #2D2D2B;  /* pressed/selected/chips. Заменяет #2D2D2B, #333, #3A3A3C */
  --color-hairline:      rgba(255,255,255,0.06);  /* разделители */
  --color-border:        rgba(255,255,255,0.10);  /* обводки контролов */
  --color-highlight:     rgba(255,255,255,0.08);  /* inset-блик по верхнему краю материала */

  /* Text */
  --color-text:          #FFFFFF;
  --color-text-secondary: rgba(255,255,255,0.62); /* заменяет #8E8E93, #888, #AAA, #9E9E9E, #B5B5B5 */
  --color-text-tertiary:  rgba(255,255,255,0.38); /* плейсхолдеры, disabled; заменяет #666, #555, #444 */

  /* Accent — ОДИН зелёный, строго по ролям */
  --color-accent:          #21EA7C;
  --color-accent-rgb:      33, 234, 124;
  --color-accent-pressed:  #1DD470;               /* уже есть в админке как --admin-primary-hover */
  --color-accent-subtle:   rgba(33,234,124,0.12); /* фон выбранного чипа, бейджа */
  --color-on-accent:       #0B0B0A;               /* текст на зелёной кнопке */

  /* Status */
  --color-danger:   #FF453A;
  --color-warning:  #F59E0B;
  --color-rating:   #FFD60A;
  --color-success:  var(--color-accent);
}
```

**Правило акцента (restraint):** зелёный используется только для (1) главного действия на экране, (2) активного состояния в навигации и табах, (3) успеха. Сейчас им красят заголовки, иконки, скроллбар, `text-shadow` и даже **дефолтный цвет текста** (`index.css:39` `--text-main: rgba(33,234,124,0.85)` → `body { color }`). Из-за этого любой текст без стиля зелёный, и акцент перестаёт работать как акцент.

### 2.2 Типографика

**Семейства: максимум два.**
- UI-текст: **Inter**. В коде он уже самый частый (≈70 объявлений) и хорошо держит кириллицу. Грузить один раз в `index.html` через `<link rel="preload">` + `font-display: swap`, variable-версию.
- Display (только лендинг и бренд-заголовки капсом): **Montserrat** 800. Это бренд, локальные TTF уже лежат в `/fonts`.
- Для KA добавить в стек `'Noto Sans Georgian'`: ни Inter, ни Montserrat не содержат грузинских глифов, сейчас KA падает в системный шрифт.
- Убрать Outfit, Plus Jakarta Sans, Rubik, Segoe UI и все 10 `@import url(fonts.googleapis…)` из CSS страниц.

**Шкала** (свёрнута из 50 значений; самые частые: 16px ×71, 15 ×54, 14 ×53, 13 ×48, 18 ×29, 12 ×28, 20 ×27, 17 ×24):

| Токен | size / line-height | tracking | weight | Где |
|---|---|---|---|---|
| `--text-display` | 34 / 1.05 | −0.02em | 800 | Лендинг, hero |
| `--text-title-1` | 28 / 1.1 | −0.02em | 700 | Заголовок экрана |
| `--text-title-2` | 22 / 1.2 | −0.015em | 700 | Секции («Категории блюд») |
| `--text-title-3` | 18 / 1.3 | −0.01em | 600 | Название блюда/ресторана в карточке |
| `--text-body` | 16 / 1.45 | 0 | 400/500 | Основной текст, **все инпуты** |
| `--text-callout` | 15 / 1.4 | 0 | 500 | Кнопки, строки списков |
| `--text-footnote` | 13 / 1.35 | 0.005em | 500 | Мета: время доставки, рейтинг |
| `--text-caption` | 12 / 1.3 | 0.01em | 500 | Бейджи, подписи |

- Tracking зависит от размера (apple-design §15): у крупного отрицательный, у мелкого слегка положительный. Сейчас «−0.5px» и «1px» стоят где попало.
- Веса: 400 / 500 / 600 / 700. 800 оставить только для display, 900 (7 мест) убрать. Сейчас 700 ×119 и 800 ×64: интерфейс «кричит».
- Глобальное `h1–h6 { text-transform: uppercase; font-weight: 800 }` (`index.css:95-106`) убрать. Капс только для бренд-display. В UI — sentence case (как уже сделано в «Категории блюд»).
- Цены: `font-variant-numeric: tabular-nums`, чтобы цифры не прыгали при изменении суммы.

### 2.3 Spacing — шкала на 4

Факт: gap 12 ×46, 8 ×36, 10 ×31, 16 ×27, 20 ×24; padding 16 ×57, 24 ×42, 12 ×37, 20 ×30.

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px; --space-12: 48px;
--gutter: 16px;  /* боковой отступ экрана на мобиле, единый */
```
Значения вне сетки (10, 14, 15, 18, 5, 6, 30) сводятся к ближайшему шагу.

### 2.4 Радиусы

Факт: 16 ×63, 20 ×51, 12 ×35, 24 ×25, 25 ×19, 28 ×14, плюс 10, 14, 15, 18, 30, 32, 34, 36, 40, 100.

```css
--radius-xs: 8px;   /* бейджи, мелкие теги */
--radius-sm: 12px;  /* инпуты, мелкие кнопки, миниатюры */
--radius-md: 16px;  /* карточки блюд, основная кнопка */
--radius-lg: 20px;  /* карточки ресторанов, баннеры */
--radius-xl: 24px;  /* панели, bottom CTA */
--radius-sheet: 28px; /* верх шторок и модалок (сейчас 28/32/36/40) */
--radius-full: 9999px;
```
**Концентричность:** внутренний радиус = внешний − padding. Кнопка 16px внутри карточки 20px с padding 4px, а не 16 внутри 16. Этот «невидимый» признак сильнее всего отличает дорогой UI.

### 2.5 Материалы и глубина

Сейчас 11 элементов с `backdrop-filter` на одном экране, **включая карточки** (`card--restaurants`, `card--shops`, `card--promos` с `blur(16px)`), и 14 разных радиусов блюра. ```css

Карточки — сплошной `--color-surface-1` без блюра.

### 4.2 Отклонено (осознанно не анимируем)

- **Переходы между табами нижней навигации:** основная навигация, десятки раз в день. Слайды не нужны, текущий `pageFlyIn 0.4s` даже сократить (G9).
- **Анимация «лайка»:** десятки раз в день, и кнопки избранного уже намеренно статичны (`index.css:186`). Уважаем это решение.
- **Hover-подъём карточек ресторанов на десктопе:** частое действие. Только смена цвета и тени, без translate.
- **Автопрокрутка ленты категорий:** это функциональный контент, который пользователь читает. Двигать его ради стиля нельзя.
- **Новые анимации иконки статуса в хедере:** наоборот, 15 существующих бесконечных анимаций надо убрать (Y7).
