## Что нужно сделать для запуска:

### Шаг 1: Обновить базу данных
Выполните в Supabase SQL Editor:

```sql
-- 1. Добавить таблицу партнерских заявок
-- Скопируйте и выполните содержимое файла: server/add_partner_requests.sql

-- 2. Добавить поле telegram_id
-- Скопируйте и выполните содержимое файла: server/add_telegram_id.sql
```

### Шаг 2: Создать Telegram бота
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте токен

### Шаг 3: Настроить .env
Добавьте в `server/.env`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
```

### Шаг 4: Запустить бота
```bash
cd server
python telegram_bot.py
```

### Шаг 5: Связать Telegram с админкой
1. Откройте вашего бота в Telegram
2. Отправьте `/start`
3. Отправьте `/link admin` (или ваш username из админки)
4. Бот ответит "✅ Аккаунт успешно связан!"

## Как проверить:

### Проверка формы:
1. Откройте главную страницу сайта
2. Нажмите "Подключить заведение" или "Стать курьером"
3. Заполните форму и отправьте
4. Зайдите в админку → Partners
5. Увидите новую заявку

### Проверка бота:
1. Откройте бота в Telegram
2. Отправьте `/orders`
3. Увидите список активных заказов
4. Создайте тестовый заказ на сайте
5. Получите уведомление в Telegram
