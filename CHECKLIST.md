# ✅ Чеклист запуска партнерской системы и Telegram бота

## 📋 Подготовка базы данных

- [ ] Открыть Supabase Dashboard → SQL Editor
- [ ] Выполнить `server/add_partner_requests.sql`
- [ ] Выполнить `server/add_telegram_id.sql`
- [ ] Проверить, что таблицы созданы (Tables → partner_requests, admin_users)

## 🤖 Настройка Telegram бота

- [ ] Открыть @BotFather в Telegram
- [ ] Отправить `/newbot`
- [ ] Придумать имя бота (например: MestiGo Partner Bot)
- [ ] Придумать username (например: @mestigo_partner_bot)
- [ ] Скопировать токен (выглядит как: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz)
- [ ] Добавить в `server/.env`: `BOT_TOKEN=ваш_токен`
- [ ] Запустить бота: `cd server && python telegram_bot.py`
- [ ] Проверить, что бот запустился (должно быть "Bot started successfully!")

## 🔗 Связывание аккаунтов

- [ ] Открыть бота в Telegram

- [ ] Получить подтверждение "✅ Аккаунт успешно связан!"

## ❌ Если что-то не работает

### Бот не отвечает:
```bash
# Проверить, что бот запущен
ps aux | grep telegram_bot.py

# Проверить логи
tail -f nohup.out

# Перезапустить бота
pkill -f telegram_bot.py
python telegram_bot.py
```

### Форма не отправляется:
1. Открыть консоль браузера (F12)
2. Проверить ошибки в Network
3. Проверить, что API доступен: `curl http://localhost:443/api/partners/requests`

### Уведомления не приходят:
1. Проверить, что telegram_id связан: отправить `/link admin` в боте
2. Проверить логи сервера
3. Проверить, что в БД есть поле telegram_id в таблице admin_users
